      Сетка провинций

      Порядок загрузки сетки: provinces.json из репозитория → кэш браузера → скачивание Natural Earth ADM-1 (~41 МБ, один раз). Положите скачанный provinces.json рядом с index.html — тогда все посетители получат лёгкую сетку сразу. Сетка, загруженная кнопкой, действует только в этой вкладке.

      Состояние карты

      Горячие клавиши

      • V выбор · B кисть · E ластик · I пипетка · P зона · N переименовать · M магнит
      • ПКМ по провинции — переименовать её (лорное название видно в тултипах и поиске)
      • Ctrl+Z / Ctrl+Y отмена / повтор · Ctrl+S сохранить
      • A названия государств на карте · R линейка: клик — точка, двойной клик / Enter — завершить, Backspace — убрать точку, Esc — очистить
      • Зона: клик ставит точку, Shift+тянуть — рисование от руки, Alt — без привязки; Enter, двойной клик или клик по первой точке завершает, Backspace убирает точку, Esc отменяет
      • Правка зоны: выберите её инструментом «Выбор» — тяните вершины, ПКМ по вершине удаляет её, кружок на ребре добавляет новую
      • «⌀ Нейтральная территория» в списке государств: нарисованная зона вырезает кусок из страны

      Как получить токен
      1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
      2. Repository access: Only select repositories → репозиторий карты.
      3. Permissions → Repository → Contents: Read and write.
      4. Токен хранится только в вашем браузере и отправляется только на api.github.com.
